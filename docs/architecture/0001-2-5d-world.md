# ADR 0001: Use a 2.5D world

- Status: Accepted
- Date: 2026-07-30

## Context

The fairground needs character movement, collision, camera following, depth
sorting, and decorative animation. Full 3D would add camera controls, modelling,
lighting, occlusion, and a larger asset and performance budget without improving
the core demo-navigation loop enough for version 1.

## Decision

Render a two-dimensional navigation plane with a fixed isometric or
near-isometric presentation. Depth is a sorting concern, not a third movement
axis. Use labelled geometric placeholders until the interaction loop is proven.

## Consequences

World data must define deliberate ground anchors and collision shapes. Artwork
can change independently of navigation logic, while a future 3D client could
still consume the same attraction and demo metadata.
