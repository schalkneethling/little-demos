# Phase 5 delivery

Build above the unmerged Phase 4 stack; do not merge either stack automatically.
The pending caption removal belongs to Phase 4, not a new labeling design.

## Review layers

1. Demo integration: port Accent Color, Crisp Edges, Layer Cake and Property
   Transitions from the existing standalone examples into lazy lifecycle-managed
   modules. Preserve their original routes. Test keyboard access, real CSS
   behavior, reduced motion, cleanup and isolation.
2. World population: give all six available demos reachable plots. Retain Arcade,
   repurpose the Ferris wheel for Zipper and carousel for Accent Color, add plots
   for the other three demos. Keep Funhouse coming soon and the central landmark.
   Validate full player-footprint routes, entrances, exits and nonoverlapping
   triggers. Improve painted paths without changing the Cartesian world model.
3. Visual integration and polish: extend approved teal/coral/cream miniature art,
   preserve silhouette selection glow, provide entrance signage and a restrained
   ambient treatment, validate camera and occlusion, capture Linux baselines and
   run the complete container browser suite plus real Chrome review.

## Execution

- Sol/high: straightforward demo ports and pure layout/data tests.
- Astra/high: CSS-layer/property scoping, integration and independent review.
- Root: stack ownership, shared registries, art generation/export, browser review
  and final validation. Agents never switch branches or stage shared files.
- Tests accompany each layer. Keep dependencies unchanged. Use the same pinned
  Linux/amd64 Docker browser environment locally and in CI.

## Boundaries

Existing categories, directory shortcuts, locate actions and persistent visited
state are reused, not reimplemented. Position restoration is optional in the
original plan and deferred: fresh loads retain the predictable entrance spawn.
No new demo concepts, audio, gamepad controls or mandatory animations. No floating
attraction-name labels. Existing player proportions remain a documented art gap.

Generated props use the approved elevated three-quarter view, warm teal timber,
coral canvas, cream trim, mustard details and sage foliage. Keep the existing HTML
type and control scale. Attraction silhouettes, not extra UI decoration, carry
the visual hierarchy. Six destinations must remain identifiable via semantic DOM
controls even if all artwork fails.
